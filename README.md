# 白馬之晨｜Hakuba Morning Photography Gallery

2025年11月2日 清晨 06:09–07:03 於日本長野縣白馬村（Hakuba, Nagano）拍攝之日出、山嵐與光影攝影展。

- **預計上線網址**：https://maskywg.github.io/hakuba-morning-gallery/
- **GitHub 儲存庫**：https://github.com/Maskywg/hakuba-morning-gallery

## 快速發布步驟（網頁拖曳上傳）
1. 前往 https://github.com/new 建立名為 `hakuba-morning-gallery` 的 **Public** 儲存庫（勾選 `Add a README file`）。
2. 在儲存庫頁面點擊 **Add file → Upload files**。
3. 將本資料夾內的 `index.html` 與 `images` 資料夾整個拖曳進網頁，點擊下方 **Commit changes**。
4. 前往 **Settings → Pages**，在 **Branch** 選擇 `main` 與 `/ (root)` 並點擊 **Save**。
